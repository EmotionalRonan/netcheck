# 极客开发导航 & 连通性测试中心 (GeekNav)

极简科技风格的开发者导航页，集成网络连通性测试。支持自由增删网址，数据保存在浏览器本地。

![主界面](screenshot.png)

## 功能特性

- 🧭 **分类导航**：搜索引擎、AI 大模型、开发框架、镜像源等 12 个分类，一键筛选
- ⚡ **连通性测速**：并发探测所有站点，显示成功/失败与延迟，重复域名自动去重
- ➕ **自由增删**：添加自定义网址，删除不再需要的站点，本地持久化保存
- 🔍 **实时搜索**：按名称或域名即时过滤
- 🌙 **明暗主题**：亮/暗模式自动适配，Liquid Glass 毛玻璃卡片 + 跟随鼠标的背景光晕

## 使用

直接用浏览器打开 `single.html` 即可。所有数据仅存储在本地浏览器中。

## 技术栈

- 纯 HTML / CSS / JavaScript，无任何外部依赖
- CSS `backdrop-filter` 毛玻璃 + GPU 合成背景动画
- `content-visibility` 提升长页面滚动性能
